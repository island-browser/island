Appearance

Each space tints the sidebar with its own color. Changes apply right away.

ThemeFollow the system, or always light or dark.
Space colorsPick a preset or type a hex color such as #7C5CFF.
Sidebar position
Page corner radiusThe page card's rounded corners (macOS).
DensityRow and control height in the sidebar.
Interface fontGeist is bundled; System uses the platform font; or name any installed family.
Reset appearanceRestores the default look (space colors stay).

Search

Used when you type something that is not an address in the address bar, and by the search box on the start page.

Search engineGoogle is the default.

History

History stays on this computer and powers results in the command palette.

Browsing historyRemove every saved history result from this device.

Tabs

Tabs you have not used for a while release their page to free memory. They stay in the sidebar, dimmed, and reload where you left off when you select them. Pinned tabs, the tab you are on, split-view partners, tabs playing audio and tabs with unsaved form input never sleep.

Sleep inactive tabsAlso in the command palette: “Sleep inactive tabs now”.

Reader

Choose the default appearance for Reader view. You can change the same controls while reading an article.

Text sizeAdjust article text from 14 to 28 pixels.
Page widthChoose how wide article text appears.
Color themeAuto follows Island's current light or dark theme.

Agent & tools

Run any Agent Client Protocol agent in the sidebar, and let external agents drive Island over MCP.

Agent in the sidebar
MCP endpoint Add this to Claude Code, Claude Desktop, Cursor, or any MCP client. The token changes on every launch.

Reports

    
Finished answers from Research mode on the start page. Open one to read it, copy it, save it, or continue it with the agent. Cmd/Ctrl+K finds them too.

    

  


  

    
Keyboard shortcuts

    
Click a shortcut, then press the new keys. Esc cancels. Shortcuts need Ctrl/Cmd or Alt, except function keys.

Import from another browser

    
Bring your bookmarks over, or recreate your Arc spaces and pinned tabs. Nothing leaves this computer.

    

  


  

    
Updates

    
Island checks its GitHub releases for new versions. Every download is checked against its published SHA-256 checksum before it is installed.
