# Command palette

The command palette is one box that finds your open tabs, your spaces, your bookmarks, your browsing history, your research reports and a few commands. It also opens web addresses.

## Open the palette

Press ⌘K (Ctrl+K). Type, use the arrow keys to move through the results, and press Enter to open one. Esc closes the palette.

## What it finds

| Result | What happens when you pick it |
| --- | --- |
| **Open tabs** of the active space | Switches to that tab |
| **Spaces** | Switches to that space |
| **Bookmarks** you imported | Opens the page |
| **History** | Opens the page from your on-device history |
| **Reports** (marked REPORT) | Opens a saved Research report |
| **A web address** you typed | Goes to it, through the same checks as the address field |
| **Sleep inactive tabs now** | Puts every eligible background tab to sleep. See [Tab sleep and Peek](../tabs/sleep-and-peek.md) |

The last word you type matches as a prefix, so `git` finds `github`. History results combine text match, recency and how often you visit a page.

{% hint style="info" %}
History search runs on your computer and nothing is sent anywhere. To stop remembering visits or to clear them, see [General settings](../settings/general.md).
{% endhint %}

## Search the web with the search palette

Press ⇧⌘K (Ctrl+Shift+K) for the **search palette**. Type a query ("Search the web") and send it to one of five providers: Google, ChatGPT, Perplexity, Claude or Gemini.

## Other ways to jump around

* ⌘L (Ctrl+L) focuses the address field. Text that looks like an address opens that page. Anything else is a web search with your default engine.
* ⇧⌘A (Ctrl+Shift+A) opens **All tabs**, with every space as searchable cards.
* ⌘/ (Ctrl+/) shows the shortcut cheatsheet.
