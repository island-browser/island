# The start page

A new tab opens on the start page. It has one search field with three modes, and a row of your most visited sites.

## Pick a mode

Click a mode in the segmented control, or press Tab (Shift+Tab goes back) while the field has focus.

| Mode | The field says | What Enter does |
| --- | --- | --- |
| **Search** | "Search with Google" (or your engine) | Searches the web, or opens the text if it is an address |
| **Ask Agent** | "Ask about this tab or anything" | Sends your question to the [agent](../agent/agent-panel.md) |
| **Research** | "Research a question — you'll see the plan first" | Starts [Research](../agent/research-and-plan.md) |

## Search the web

1. Leave the mode on **Search**.
2. Type what you want, or paste an address.
3. Press Enter.

To change the engine (Google or DuckDuckGo), go to **Settings > General > Search**. The address field uses the same engine.

## Ask the agent

1. Choose **Ask Agent**.
2. Type your question and press Enter.

The agent panel opens with your question. You need an agent set up first. See [The agent panel](../agent/agent-panel.md).

## Research a question

1. Choose **Research**.
2. Type a question and press Enter.
3. Review the plan in the Plan tab, then approve it.

Nothing runs until you approve. When it finishes, the report opens in a Report tab. If no agent is configured, the start page tells you and offers **Open Settings**. If the agent is busy, wait for it or cancel. See [Research and the Plan tab](../agent/research-and-plan.md).

## Open a most visited site

Below the field, up to six tiles show the sites you visit most, one per site, built from your on-device history. Click a tile to open it in the current tab. Clearing your history clears the tiles.
