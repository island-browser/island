# Bookmarks and favorites

Open the Bookmarks page to manage Island's local bookmark library.

## Use bookmarks from ⌘K

Press ⌘K (Ctrl+K) and search by bookmark name or address. Each matching bookmark shows its folder
in muted text; favorite bookmarks also show `Global` or their space name. The palette's **Bookmarks**
group offers **Open Bookmarks**, **Add bookmark**, add/remove global or current-space favorite,
**New folder**, and **Open Bookmarks to import…**. A favorite you are viewing can also move earlier
or later in its list with **Move … favorite** rows. **New folder** creates a folder named “New
folder,” which you can rename on the Bookmarks page. The bookmark commands act on the page you are
looking at; a page that cannot be bookmarked (Settings, the start page, or a non-web address) does
not list them.

Use the search field to find a bookmark by its title, address, or folder. Select a folder to show
only its bookmarks. You can create, rename, and delete folders from the folder actions.

Select a bookmark title (or focus its row and press Enter) to open it. Its `...` menu opens it in a
new tab, changes favorites, moves it to a folder, edits it, or deletes it. The row labels favorites
as **Global** and by their actual space names. Deleting a non-empty folder lets you move its
bookmarks to Unfiled or permanently delete the bookmarks and their favorite entries.

Use the `...` menu to make a bookmark a global favorite or a favorite only in the current named
space. A bookmark can be in both scopes.

The Import menu lists browsers Island detects on this computer. Imports add only new addresses, so
you can safely import the same source again.

Island validates a saved address when you open it. If an old or unsupported address cannot open,
the Bookmarks page leaves it unchanged and shows an accessible status message. Import outcomes use
a separate status, so they do not hide a pending failed-save Retry. If a change cannot be saved,
Island rolls it back and offers Retry.
