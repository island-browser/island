# Tab sleep and Peek

**Planned.** This page is not written yet.

Tab sleep frees memory from tabs you are not using. Peek shows a link in a floating card without leaving your page.

## Sleeping favorites

A favorite you open from the sidebar has its own tab. When you switch to another tab, that favorite's tab follows the same sleep timer as any other tab. While the favorite is on screen it never sleeps. When you open it again, it wakes at the page where you left it.
