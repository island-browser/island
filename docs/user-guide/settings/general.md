# General settings

**Planned.** This page is not written yet.

The General section covers search, history, imports and updates.

Settings opens as an ordinary tab in the current space. There is one Settings tab per window:
opening any Settings section again focuses that tab. You can switch to it, reorder it and close it
with ⌘W (Ctrl+W). Settings is intentionally not restored after restarting Island.
