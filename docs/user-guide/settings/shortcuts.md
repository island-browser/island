# Shortcuts

Every shortcut in Island can be changed. Open **Settings > Shortcuts** (⌘, or Ctrl+,).

## Change a shortcut

1. Click the shortcut you want to change. The row shows an outline and "Press keys…".
2. Press the new keys. To cancel, press Esc.
3. If another action already uses those keys, an amber banner says so, for example "⌘B is already used by Toggle sidebar." Click **Replace** to move the keys to this action (the other action loses its shortcut), or **Cancel**.

A shortcut needs ⌘/Ctrl or ⌥/Alt, except function keys. Plain typing keys are never captured.

## Add or remove a shortcut

* An action without keys offers **Add shortcut**. Click it, then press the keys.
* Replacing a shortcut with **Replace** unbinds the action that had those keys.

## Go back to the defaults

Click **Reset all** to restore every default.

{% hint style="info" %}
**macOS only:** the menu bar picks up your changes after you restart Island.
{% endhint %}
