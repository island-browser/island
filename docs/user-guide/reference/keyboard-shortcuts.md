# Keyboard shortcuts

These are Island's default shortcuts. All of them can be changed in [Settings > Shortcuts](../settings/shortcuts.md).

* On macOS, ⌘ is Command, ⌥ is Option, ⇧ is Shift and ⌃ is Control.
* On Windows and Linux, the main modifier is Ctrl.

## The cheatsheet

Press ⌘/ (Ctrl+/) for a card in the bottom-right corner that lists the ten most-used shortcuts with their current keys: Command palette, Ask agent, Toggle sidebar, Split view, New tab, Close tab, Find in page, Reader view, Settings and Cheatsheet. Press the keys again, press Esc, or click the close button (or click outside, on macOS) to close it.

## Also in the app

* In the Plan tab, the arrow keys move between steps.
* In **All tabs**, use the arrow keys, Enter, Delete and P.
* In the find bar, Enter goes to the next match and Shift+Enter to the previous one.
