# FAQ

**Partly written.** The extensions answer below is current; the other questions are still planned.

Short answers to common questions.

## Can I install extensions?

No. Island does not run browser extensions, including the Chrome Web Store's "Add to Chrome" button, because it uses the Alloy runtime.
