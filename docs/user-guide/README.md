# Island user guide

Island is a desktop web browser with a built-in AI agent. It has a sidebar of tabs and spaces,
split view, a command palette, a start page with Search, Ask Agent and Research modes, and native
ad and tracker blocking. Your history stays on your computer.

This guide is task-first: each page tells you how to do one thing.

## Start here

* [Install Island](getting-started/install.md) and [open it for the first time](getting-started/first-launch.md).
* [Organize tabs with spaces](basics/tabs-and-spaces.md) and [work in a split view](basics/split-view.md).
* [Find anything with the command palette](search/command-palette.md).
* [Ask the agent](agent/agent-panel.md) or [research a question](agent/research-and-plan.md).
* [Look up a shortcut](reference/keyboard-shortcuts.md).

## Conventions

* Shortcuts are written for macOS first. On Windows and Linux, use Ctrl where macOS uses ⌘, and Alt where it uses ⌥.
* Behavior that exists only on macOS is marked **macOS only**.
* Island is pre-1.0 and every build is an unsigned prerelease. Some pages are still being written; they are marked **Planned**.
