# Island app icons: Paper Relief, Liquid Glass, user choice

Status: Accepted (owner, 2026-10-27: "Paper Relief но можно типо выбор добавить и чтобы для ликвид
гласс, была ликвид гласс иконка и давай сделаем возможность выбора все такие для пользователя").

## 1. Goals

1. **Default icon.** Paper Relief (concept `paper` of `~/hsse/agents/reports/brand/contour/`)
   replaces the Dawn placeholder everywhere: `.icns`, `.ico`, Linux PNG/SVG, dmg window.
2. **Liquid Glass.** On macOS 26 and later the Dock, Finder and Launchpad show a layered Liquid
   Glass icon (light, dark, clear and tinted appearances drawn by the system). Older macOS keeps the
   flat `.icns`.
3. **User choice.** Settings > Appearance > App icon offers Automatic (Paper Relief) plus the eight
   Contour variations: bold, shore, archi, summit, graphite, paper, glass, ink. Each follows the
   light/dark appearance of the system.

## 2. Non-goals

- Rewriting files inside the installed app bundle. It breaks the code signature that 0.13
  notarization relies on. The choice lives in `prefs.json` only.
- Per-space icons, user-supplied images, seasonal icons.
- Changing the Windows shortcut or the Linux `.desktop` icon after install.

## 3. Design

### 3.1 Liquid Glass asset (macOS 26+)

- `resources/brand/Island.icon/` is an Icon Composer document committed as text plus layer
  images: `icon.json` and `Assets/` holding 2-4 SVG layers split from the Paper Relief art
  (background fill, sea rings, land tones, top highlight). `scripts/brand_icons.py glass <concept>`
  writes it from the concept SVG, so the document is reproducible.
- The macOS build compiles it with `xcrun actool Island.icon --compile <Resources>
  --platform macosx --minimum-deployment-target 26.0 --app-icon Island
  --output-partial-info-plist <file>` into `Assets.car`. `Info.plist.in` gets
  `CFBundleIconName = Island` next to the existing `CFBundleIconFile = island`, so macOS 15 and
  older keep using `island.icns`.
- When `actool` is missing or older than the one in Xcode 26, CMake prints one warning and builds
  with the `.icns` only. CI must not fail on that.

### 3.2 Default artwork

`python3 scripts/brand_icons.py install-concept paper-light.svg paper-dark.svg paper-dmg.svg`
regenerates every derived file. `tests/package/test_brand.py` keeps its label-contrast checks.

### 3.3 Icon choice

- Pref `appearance.app_icon`: one of `auto`, `bold`, `shore`, `archi`, `summit`, `graphite`,
  `paper`, `glass`, `ink`. Unknown or missing means `auto`. `auto` changes nothing at run time:
  the system shows the bundle icon (Liquid Glass on macOS 26).
- The bundle carries `Resources/app-icons/<id>-{light,dark}.png` (1024 px, generated by
  `brand_icons.py`) for the eight ids. They are resources, never rewritten after build.
- macOS, while running: `NSApplication.applicationIconImage` is set from the PNG matching the
  effective appearance, at startup and on change. An appearance change (light/dark) re-applies it.
  Choosing `auto` sets it back to `nil`.
- macOS, app not running: a Dock tile plug-in (`Contents/PlugIns/IslandDockTile.docktileplugin`,
  `NSDockTilePlugIn`) reads the pref from the shared `prefs.json` path and draws the chosen icon in
  the Dock. Finder keeps the bundle icon; macOS offers no unsigned way to change it. Settings says
  so in one line under the picker.
- Windows and Linux: the window and taskbar icon (`WM_SETICON` / the GTK window icon) use the
  chosen PNG. Shortcuts and the installed `.desktop` file keep the bundle icon.
- Settings > Appearance shows a grid of 9 tiles (48 px icon, name under it). The selected tile has
  the neutral selected fill and the neutral rounded focus ring; no accent. Theme tokens only.
- The agent gets no tool for this setting.

## 5. Acceptance

- `assetutil --info Assets.car` lists the `Island` icon; on this Mac (macOS 26) the Dock shows the
  glass icon in light, dark and tinted modes (captures of each).
- With `appearance.app_icon = ink` the running Dock icon is Ink in light and dark; after quit the
  Dock tile still shows Ink (I3).
- `codesign --verify --deep` passes before and after switching icons (ad-hoc signature).
- ctest, `pytest tests/design tests/package` green.
