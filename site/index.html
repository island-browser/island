An open-source native browser v0.4.0 · What’s new

A calm browser, with an agent at your side.

Island is a native desktop browser built directly on CEF — no Electron, no web app shell. A sidebar tinted by each space holds your pinned and open tabs, an AI agent lives one keystroke away, and any agent you already use can drive the browser through its tools.

Why it's being built

The browser chrome should get out of the way.

Island keeps the interface small and legible so the page stays in front. Everything it adds — spaces, split view, palettes, an agent — lives in the same calm sidebar or behind one keystroke, and every feature listed on this site is in the current source.

The browser, today

What the current build actually has.

Working pieces of the build in development — not a roadmap and not a promise of what's next. See the changelog for what landed when.

01

An agent in the sidebar

Press Cmd+J and an Agent Client Protocol agent opens beside the page — Claude Code by default, or any ACP agent you configure. Replies stream in, tool calls ask before they act, and the agent already knows which tab you are looking at.

New in 0.4
02

Tools any agent can use

Island serves its browser as MCP tools on a loopback-only endpoint: list and open tabs, switch spaces, read page text, take screenshots, evaluate JavaScript, and pin tabs. Point Claude Code, Cursor, or any MCP client at it — Settings has the config ready to copy.

New in 0.4
03

Spaces that color the sidebar

Each space is a named, colored context with its own tabs, and the sidebar takes on its tint — always above WCAG contrast. Pinned tabs sit in a tray at the top (Cmd+D), the address lives in the sidebar, and the page floats on a card.

New in 0.4
04

All tabs at a glance

Cmd+⇧+A lays every space's tabs out as searchable cards. Arrow keys and Enter jump to one, Delete closes, P pins, and dragging a card onto another space moves it there.

New in 0.4
05

Settings and your own shortcuts

Cmd+, opens Settings: theme, the agent command, the MCP config, and every keyboard shortcut. Click a shortcut, press new keys, and Island flags conflicts; reset one or all to the defaults.

New in 0.4
06

Bring everything with you

Import bookmarks from Chrome, Edge, Brave, and other Chromium-family browsers, Safari, and Firefox — or recreate your Arc spaces with their colors and pinned tabs. Everything is read from disk on your machine; nothing is uploaded.

New in 0.4
07

Split view

Pair any two tabs of a space side by side with a keyboard-adjustable divider. Closing either half — or selecting a tab outside the pair — returns the survivor to full width.

In the build
08

Command and search palettes

Cmd+K opens a keyboard-first palette listing open tabs, spaces, and your bookmarks, with a go-to-URL affordance through the same validation as the address bar. Cmd+⇧+K searches the web with your pick of providers.

In the build
09

Session restore

Quit cleanly and Island rebuilds your spaces, tabs, pins, and active selections on the next launch — including split pairs. Restored URLs pass the same validation as anything you type; nothing bypasses policy.

In the build

Made for agents

Your agent can use the browser you use.

While Island runs, it listens on 127.0.0.1 only, behind a bearer token that changes on every launch. Add this to any MCP client, or use the island_mcp_bridge stdio bridge for clients that only speak stdio.

{
  "mcpServers": {
    "island": {
      "type": "http",
      "url": "http://127.0.0.1:9223/mcp",
      "headers": {
        "Authorization": "Bearer <token from Settings>"
      }
    }
  }
}

Some of the 22 tools

  • browser_list_tabs / browser_list_spaces — everything that is open
  • browser_open_tab / browser_navigate — go somewhere
  • page_read / page_snapshot — the page as text or as clickable elements
  • page_click / page_type / page_scroll — act on the page
  • page_screenshot — what the page looks like
  • browser_switch_space / browser_pin_tab — organize

Availability

Where you can run it.

Honest platform status for the in-development build. Signed public releases are still to come.

In development

macOS

Island is built and verified on Apple silicon. You can build it from source today — the quick start takes a few minutes.

Planned

Windows & Linux

The code targets Windows and Linux (x64 and arm64) and CI builds search and packaging on all six platforms, but native browser builds still need platform verification.

Open source

Built in the open.

Island is made in public: phase specs, plans, and acceptance checklists live in the repository next to the code. Read the docs, run the tests, or contribute when the project is ready for you.
