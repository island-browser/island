An open-source browser

A calm place to browse, one page at a time.

Island is a native desktop browser in development. It puts a single quiet rail to the left of the page: back, forward, reload, one address, and the page you're on.

Island Browser

This is the local page the app opens with — no network request.

What runs today. The current macOS build opens one native window with the rail shown here and a local starting page. It is a real foundation, not a finished browser.

Why it's being built

The browser chrome should get out of the way.

Island keeps the interface small and legible so the page stays in front. Navigation, an address, and the current page live in one calm rail at the left edge — nothing more competes for your attention.

The rail, today

What the current build actually has.

These are the working pieces of the macOS build in development — not a roadmap and not a promise of what's next.

01

Back and forward

Move backward and forward through the current page's history from the top of the rail. Keyboard shortcuts work too.

Working in the build
02

One address

A single address field accepts a URL and takes you there. It validates what you type and keeps the current address in view when you're not editing it.

Working in the build
03

Reload

Reload the current page from beside the address field, or with the usual keyboard shortcut.

Working in the build
04

The current page

One row at the foot of the rail shows the page you're on, with an accent line marking it as active. Selecting it returns focus to the page.

Working in the build

Availability

Where you can run it.

Honest platform status for the in-development build. Signed public releases are still to come.

In development

macOS

Island is being built and verified on macOS first. The current build runs on Apple silicon; broader macOS and notarized releases are still in progress.

Planned

Windows & Linux

Support for Windows and Linux is planned. Those builds still need platform verification before they're treated as available.

Built in the open.
