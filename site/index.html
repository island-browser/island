An open-source native browser

A calm place for every page you keep open.

Island is a native desktop browser built directly on CEF — no Electron, no web app shell. One quiet rail holds your tabs, your spaces, and the page you're on; split view and a command palette are one keystroke away.

Why it's being built

The browser chrome should get out of the way.

Island keeps the interface small and legible so the page stays in front. Everything it adds — tabs, spaces, split view, palettes — lives in the same calm rail or behind one keystroke, and every feature listed on this site runs in the current build.

The rail, today

What the current build actually has.

Working pieces of the macOS build in development — not a roadmap and not a promise of what's next.

01

Tabs and spaces

A tab strip and a space switcher live in the rail. Spaces are colored, named contexts with their own tabs; rename with F2 or the menu, reorder from the menu, and switch from the rail or the palette.

Working in the build
02

Split view

Pair any two tabs of a space side by side with a keyboard-adjustable divider. Closing either half — or selecting a tab outside the pair — returns the survivor to full width.

Working in the build
03

Command and search palettes

Cmd+K opens a keyboard-first palette listing open tabs, spaces, and your bookmarks, with a go-to-URL affordance through the same validation as the address bar. Cmd+⇧+K searches the web with your pick of providers.

Working in the build
04

Import from your browser

The first-run welcome offers to bring bookmarks in from browsers already on your machine — Chrome, Edge, Brave, and other Chromium-family browsers, plus Safari where the system allows — and an appearance choice of System, Light, or Dark.

Working in the build
05

Session restore

Quit cleanly and Island rebuilds your spaces, tabs, and active selections on the next launch — including split pairs. Restored URLs pass the same validation as anything you type; nothing bypasses policy.

Working in the build
06

Navigation and the address bar

Back, forward, and reload with the usual shortcuts; one address field that validates what you type against a strict local allow-list before it ever loads.

Working in the build

Availability

Where you can run it.

Honest platform status for the in-development build. Signed public releases are still to come.

In development

macOS

Island is built and verified on Apple silicon. You can build it from source today — the quick start takes a few minutes.

Planned

Windows & Linux

The code targets Windows and Linux (x64 and arm64) and CI builds search and packaging on all six platforms, but native browser builds still need platform verification.

Open source

Built in the open.

Island is made in public: phase specs, plans, and acceptance checklists live in the repository next to the code. Read the docs, run the tests, or contribute when the project is ready for you.
